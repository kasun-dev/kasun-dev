### About

- Associate at **Axceera**, working full-time and remotely
- BSc (Hons) in Information Technology, Software Engineering, **SLIIT** (graduated 2026)
- Main stack: React, Next.js, NestJS, PostgreSQL, AWS and ESP32
- Outside work I run **[Studio Click.ed](https://www.studioclicked.com)**, a photography studio, and shoot as [click.ed_by](https://www.instagram.com/click.ed_by/)

### Selected projects

- **AR–AI Guided Maintenance**: final-year research project. I built the IoT part: ESP32 sensor nodes sending vibration data over ESP-NOW to a gateway and on to AWS IoT Core, Lambda and DynamoDB
- **YPVS controller**: an ESP32-S3 controller for a Yamaha TZR125 that reads engine RPM and drives the power valve
- **Swagger PowerAuth**: a Chrome extension I use daily for API testing

More on the [portfolio](https://kasun-dev.github.io/portfolio-web).
